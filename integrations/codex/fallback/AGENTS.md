# engram agent kit

Before changing load-bearing code, search the engram ledger for the decision
that explains it. Use the engram MCP tools or the engram CLI.

When the work reveals a durable decision, record it as a migration in
.agents/memories, run engram sync, and commit the migration with the code.
Use topic reader when the reader model learned a useful correction.

For user-facing writing, load the reader skill and follow the reader card.
For long reports, use the reader-writer skill. When an explanation misses,
record the missed term or framing and what helped as a reader memory.
